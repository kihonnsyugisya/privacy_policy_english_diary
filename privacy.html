プライバシーポリシー

適用範囲

このプライバシーポリシーは、Yoshihiro Tanabeが提供する「英語日記」アプリ（以下「本アプリ」）に適用されます。

1. 収集する情報

本アプリでは、以下の情報を収集・利用いたします：

  • 日記データ：ユーザーが入力した日記の内容、翻訳結果、添削アドバイス
  • マイ単語帳データ：ユーザーが保存した単語・フレーズ
  • アカウント情報：Firebase Authentication によるユーザーID（UID）。初回利用時は匿名認証を用いる場合があります。
  • 連携アカウント情報：Apple または Google でデータ引き継ぎ（連携）を行った場合、認証プロバイダから提供される識別子（メールアドレス等が含まれる場合があります）、連携種別（Apple / Google）、および連携・端末切り替えの履歴に関する情報（過去の匿名 UID 等）
  • 使用状況データ：翻訳・添削機能の利用回数や制限情報
  • 通知設定：日記リマインダーの時刻設定

2. 情報の利用目的

収集した情報は、以下の目的で利用いたします：

  • 本アプリのサービス提供（日記の保存・表示、翻訳・添削機能）
  • Apple または Google によるデータ引き継ぎ（連携）、端末の入れ替え後の利用継続
  • 連携先に既存データがある場合の、ユーザー選択に基づくデータ統合
  • サービスの改善・品質向上
  • 不正利用の防止
  • 通知機能の提供

3. データの保存・管理

  • Firebase：日記データ、マイ単語帳、アカウント情報は Firebase（Google Inc.）の Firestore に保存されます。認証は Firebase Authentication（匿名認証、Sign in with Apple、Google サインイン）を使用します。
  • 匿名利用と連携：連携を行わない場合、メールアドレス等の個人を特定できる情報を本アプリが直接お尋ねすることはありません。連携を行った場合、認証プロバイダから提供される情報（メールアドレス等）が Firebase および Firestore 上のユーザー情報として保存されることがあります。
  • RevenueCat：サブスクリプションの状態確認のため、RevenueCat（RevenueCat Inc.）にアプリ内ユーザー識別子を送信する場合があります。
  • ローカルデータ：アプリの設定情報は端末内のローカルストレージに保存されます。

4. 広告

本アプリでは、広告配信ツールとしてAdMob（Google Inc.）を使用しており、AdMobがご利用者の情報を自動取得する場合がございます。取得する情報、利用目的、第三者への提供等につきましては、以下の広告配信事業者のアプリケーション・プライバシーポリシーのリンクよりご確認ください。

Google広告に関するポリシーはこちら

5. サブスクリプション

本アプリでは、RevenueCat（RevenueCat Inc.）を利用してサブスクリプションサービスを提供しています。サブスクリプションの購入・管理に関する情報は、Apple App StoreまたはGoogle Play Storeを通じて処理されます。

詳細については、各ストアの利用規約・プライバシーポリシーをご確認ください。

6. 外部サービスの利用

本アプリでは、以下の外部サービスを利用しています：

  • Firebase（Authentication / Firestore）：認証、アカウント連携、データ保存
  • Google Translate API：日記の翻訳機能
  • OpenAI API：日記の添削・アドバイス機能
  • Google Cloud Text-to-Speech API：音声読み上げ機能
  • RevenueCat：サブスクリプション管理

翻訳・添削・音声合成 API に送信されるデータは、各機能の提供目的のみに使用されます。認証・連携に関するデータの取扱いについては、各サービス提供者のプライバシーポリシーをご確認ください。

7. データの削除

ユーザーは、アプリ内の「プライバシー設定」からアカウントを削除することで、当該ユーザーID（UID）に紐づく日記データおよびマイ単語帳データを削除することができます。アカウント削除後も、ユーザーID（UID）は保持され、悪用防止のための利用制限情報は継続されます。

データ引き継ぎ（連携）の際、既存の連携先アカウントに別端末等のデータがある場合、統合せずに切り替えを選んだとき、切り替え前の端末上の日記・マイ単語帳は本アプリからは利用・復元できません。統合を選んだ場合、当該端末のデータは連携先アカウントにコピーされます。運用上、切り替え前の匿名ユーザーIDに紐づくデータがサーバー上に残る場合や、連携先アカウントに連携履歴の情報が記録される場合があります。

8. 第三者への提供

本アプリは、法令に基づく場合を除き、ユーザーの同意なく個人情報を第三者に提供することはありません。

9. 変更

本アプリでは、利用者の了承を得ることなく、「プライバシーポリシー」を変更することがあります。重要な変更の場合には、本アプリ上で改めて通知し、利用者の同意を取得します。
